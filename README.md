Managed with [GNU stow](https://www.gnu.org/software/stow/)

## Install on a new machine

```sh
git clone git@github.com:OvidioCalvet/dotfiles.git ~/.dotfiles
cd ~/.dotfiles && stow -t ~ ghostty starship tmux zsh hypr waybar
```
